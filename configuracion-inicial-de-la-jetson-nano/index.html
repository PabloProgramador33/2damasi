Configuración inicial de la jetson nano

Para comenzar el proceso, se abre la caja del dispositivo y se comprueba el estado general del equipo. En este punto se puede observar la Jetson Orin preparada para su primera configuración y todos los elementos incluidos en el paquete.

 

Cuando el dispositivo está listo, se procede a insertar la tarjeta SD de 128 GB. Esta tarjeta se coloca dentro del disipador de calor, orientada con los pines hacia arriba, ya que de esta forma la Jetson la detecta correctamente y permite continuar con la preparación del sistema.

 

 

 

 

 

 

 

 

 

Una vez insertada la tarjeta, se preparan las conexiones necesarias. Se conecta el monitor mediante un cable DisplayPort y se deja lista la fuente de alimentación. La Jetson Orin no dispone de un interruptor de encendido, por lo que comenzará a arrancar automáticamente en cuanto reciba corriente.

 

Al iniciarse por primera vez, el dispositivo carga el sistema operativo Ubuntu que incorpora de fábrica. A partir de ese momento se pueden realizar los ajustes iniciales habituales, como la selección del idioma, la conexión a Internet y la creación del usuario principal. El sistema también configura la partición y completa la instalación de aplicaciones básicas como el navegador Chrome.

Finalizada la configuración inicial, se recomienda dejar que el sistema realice todas las actualizaciones disponibles mediante el gestor de actualizaciones de Ubuntu. Este proceso asegura que los controladores y componentes preinstalados funcionen correctamente y que el dispositivo pueda ofrecer el mejor rendimiento posible.

Una vez actualizado, se puede instalar JetPack 6.2.1, un conjunto de herramientas oficiales de NVIDIA que optimiza el rendimiento del dispositivo y mejora su comportamiento en tareas de inteligencia artificial. Esta actualización incrementa la eficiencia general del sistema y permite ejecutar modelos más exigentes con mayor fluidez.
[FOTO 6 AQUÍ]

 

Conviene tener en cuenta que Ubuntu viene preparado para utilizar aplicaciones Snap, aunque en la Jetson algunas de ellas pueden no funcionar correctamente de forma predeterminada. Para solucionar esto, se pueden aplicar ajustes adicionales que permiten mejorar su compatibilidad y evitar problemas futuros.
